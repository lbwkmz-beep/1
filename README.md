# AI Video Studio для Fish Audio

Небольшое локальное приложение с интерфейсом для подготовки роликов:

1. Генерирует промпты для фото и промпты для оживления/animation по одному мастер-промпту.
2. Озвучивает текст через Fish Audio Text-to-Speech API.
3. Собирает фото/видео, озвучку, субтитры и фоновую музыку в один MP4 ролик, который можно скачать.

Также сохранён CLI-скрипт `fish_voiceover.py`, если нужна только озвучка без интерфейса.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для раздела монтажа нужен установленный `ffmpeg`:

```bash
ffmpeg -version
```

## Запуск интерфейса

```bash
export FISH_API_KEY="ваш_ключ"
streamlit run app.py
```

После запуска откроется web-интерфейс с тремя вкладками.

### 1. Промпты

- Вставьте мастер-промпт.
- Выберите стиль, формат кадра и количество сцен.
- Приложение создаст для каждой сцены:
  - промпт для генерации фото/keyframe;
  - промпт для оживления фото в видео;
  - negative prompt.
- Все промпты можно скачать одним `.txt` файлом.

### 2. Озвучка

- Вставьте сценарий ролика.
- Укажите `Fish Audio API key` или задайте переменную окружения `FISH_API_KEY`.
- При необходимости укажите `reference_id` голоса, модель, формат аудио и параметры нормализации.
- Нажмите `Сгенерировать озвучку`, прослушайте результат и скачайте аудио.

### 3. Монтаж

- Загрузите фото или видео для ролика.
- Используйте озвучку из вкладки `Озвучка` или загрузите готовый аудиофайл.
- Добавьте текст субтитров и фоновую музыку, если нужно.
- Выберите длительность показа фото, разрешение и громкость музыки.
- Нажмите `Собрать ролик`, после чего итоговый MP4 можно просмотреть и скачать.

## CLI: только озвучка

```bash
export FISH_API_KEY="ваш_ключ"
python fish_voiceover.py --text "Привет! Это тестовая озвучка для ролика." --output voiceover.mp3
```

Озвучка из файла со сценарием:

```bash
python fish_voiceover.py --text-file script.txt --reference-id "voice_model_id" --output output/voiceover.mp3
```

Можно также передать текст через stdin:

```bash
echo "Текст ролика" | python fish_voiceover.py --output voiceover.mp3
```

## Основные параметры CLI

- `--text` — текст для озвучки.
- `--text-file` — путь к UTF-8 файлу со сценарием.
- `--output`, `-o` — путь для сохранения аудио, по умолчанию `voiceover.mp3`.
- `--reference-id` — ID голоса Fish Audio.
- `--model` — модель Fish Audio, по умолчанию `s2.1-pro`.
- `--format` — формат результата: `mp3`, `wav` или `pcm`.
- `--normalize` / `--no-normalize` — включить или отключить нормализацию текста.

## Примечание по Fish Audio

Скрипт использует REST endpoint `POST https://api.fish.audio/v1/tts`, заголовок `Authorization: Bearer $FISH_API_KEY` и заголовок `model` для выбора модели. По документации Fish Audio для production рекомендуется модель `s2.1-pro`; для тестов можно указать `--model s2.1-pro-free`, если она доступна вашему аккаунту.
